# P12 Call Load Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an interactive load generator (`tools/call_load_generator.py`) as a standalone SIP-speaking process, add per-call event emission hooks to both AS CallControllers, and prove concurrent `CallController` isolation under genuine load (≥ 10 concurrent calls per AS).

**Architecture:** Generator is a closed-loop leaky-bucket concurrency pool with an open-loop call-rate throttle (Little's Law coupling, ADR-0013). It reuses sippy's `UA` pattern from `src/s_sbc_mock/uac.py` but runs as an independent asyncio process. AS event emission extends each AS instance's `internal_api.py` with a process-local pub/sub broadcast mechanism — no `as_platform` changes (REQ-NF-027). Each `CallController` receives a FastAPI `app` reference at construction and calls `app.state.broadcast(json)` from 7 lifecycle points.

**Tech Stack:** Python 3.12, FastAPI (REST + WebSocket, already dependency), sippy (SIP UAC, already dependency), asyncio (pool tick loop + race handling), pytest + pytest-asyncio (tests)

## Global Constraints

- **REQ-NF-027** — P12 does not modify `as_platform`. No new Transport, StateStore, or library method. Event emission is AS-local internal_api extension.
- **REQ-NF-029** — Generator (`tools/call_load_generator.py`) does not import `src/as_app`, `src/anti_fraud_as`, or `as_platform`. It talks only SIP + observes events.
- **AGENT.md §6** — sippy `ED2.loop()` must stay event-driven and non-blocking. No synchronous I/O inside sippy callbacks.
- **AGENT.md §9** — No private keys or certificates committed. Generator does not need TLS (UDP only, P12 scope).
- **REQ-NF-030** — Integration and e2e tests exercise genuine concurrent load, not sequential one-call-at-a-time in the same file. Must launch ≥ 10 concurrent calls per AS.
- **P12 does not change**: SIP signalling, routing rules, anti-fraud verdict engine, chained topology wiring, sippy source.
- **Commits follow conventional commits** with `feat(phase3):` prefix.

## Review Focus

1. **Asyncio vs sippy thread boundary** — MockSipUac's sippy callbacks fire on sippy's internal thread, but CallPool's asyncio structures need async context. The `_on_call_ended` callback bridges via `asyncio.create_task()` — but is the event loop reference safe? What if the generator's asyncio loop and sippy's loop are on different threads? (A generator starts its own asyncio event loop on the main thread; sippy runs `ED2.loop()` on the same thread? Different? **This is the #1 risk.**)

2. **CallController construction signature change** — Adding `app: FastAPI | None = None` to both `CallController.__init__` signatures is additive and backward-compatible, but every construction site in `as_stack.py`, test fixtures, probe tools must pass the new arg. Missing one = runtime error.

3. **WebSocket broadcast threading** — `app.state.broadcast()` is called from sippy callbacks (potentially non-asyncio context). FastAPI's WebSocket is async. The broadcast must handle being called from a non-async context (use `asyncio.run_coroutine_threadsafe` or similar).

4. **Generator's port independence** — The generator's FastAPI REST/WebSocket (5095) must not conflict with AS internal APIs (5090/5092) or console (5000). `.env.example` must document the new port.

5. **P8a timer isolation under concurrency** — The sharpest test edge. When 10 concurrent calls hit the AS with unreachable next hops, each CallController's P8a tear-down timer (3 s) fires independently. If timer cancellation leaks between controllers, the test will find it. The test must assert specific timer independence, not just "all 10 calls end".

```python
# tools/call_load_generator.py (first ~100 lines)

"""Interactive SIP load generator for P12 Call Load capability.

Standalone Python process — does not import as_platform, src/as_app, or
src/anti_fraud_as (REQ-NF-029). Talks to AS processes via real SIP INVITEs
on the configured listen port and observes via WebSocket event streams.
"""
from __future__ import annotations

import random
import time
from dataclasses import dataclass, field
from typing import Final


# ---------------------------------------------------------------------------
# Call type model — weighted-random selection of the 10 call types
# (HLD §12.3, LLD §12.2, phase3-plan.md §D7)
# ---------------------------------------------------------------------------

class CallModel:
    """Weighted-random selection across translation types (T1–T6) and
    anti-fraud types (F1–F4). All 10 types have equal weight; toggling is
    handled by passing the enabled set to :meth:`pick`.
    """

    ALL_TYPES: Final[frozenset[str]] = frozenset(
        {f"T{i}" for i in range(1, 7)} | {f"F{i}" for i in range(1, 5)}
    )

    # Equal weights — every type is equally likely when enabled
    _base_weights: Final[dict[str, float]] = {t: 1.0 for t in ALL_TYPES}

    @classmethod
    def pick(cls, enabled_types: set[str]) -> str:
        """Return one call type from the enabled set via weighted random.

        Args:
            enabled_types: Subset of :attr:`ALL_TYPES` the caller has toggled on.

        Returns:
            One type string (e.g. ``"T1"``, ``"F2"``).

        Raises:
            ValueError: When ``enabled_types`` is empty or contains unknown keys.
        """
        if not enabled_types:
            raise ValueError("enabled_types must not be empty")
        unknown = enabled_types - cls.ALL_TYPES
        if unknown:
            raise ValueError(f"Unknown call types: {unknown}")
        # Build weights dict filtered to enabled types
        weights = [cls._base_weights[t] for t in enabled_types]
        return random.choices(sorted(enabled_types), weights=weights, k=1)[0]


# ---------------------------------------------------------------------------
# Duration model — fixed 30/50/15/5 weights (HLD §12.4, LLD §12.2, REQ-F-041)
# ---------------------------------------------------------------------------

class DurationModel:
    """Fixed-weight duration classes governing the mock S-CSCF's far-end
    behaviour (HLD §12.4).
    """

    WEIGHTS: Final[dict[str, float]] = {
        "D1": 0.30,  # Fast: ~2s conversation
        "D2": 0.50,  # Medium: ~8-15s conversation
        "D3": 0.15,  # Long: ~20-30s conversation
        "D4": 0.05,  # Timeout: never answer, AS tears down on 3s timer
    }

    #: Midpoint BYE timing for each class (seconds after 200 OK receipt).
    #: For D4 this is the timeout the AS's 3 s no-answer timer will trigger at.
    MIDPOINTS: Final[dict[str, float]] = {
        "D1": 2.5,
        "D2": 11.5,
        "D3": 25.0,
        "D4": 3.0,
    }

    #: Weight-derived average duration, used for Little's Law coupling.
    #: Design constant (ADR-0013), not a runtime measurement.
    AVG_DURATION_SECONDS: Final[float] = (
        0.30 * 2.5 + 0.50 * 11.5 + 0.15 * 25.0 + 0.05 * 3.0
    )  # = 9.5

    @classmethod
    def pick(cls) -> str:
        """Return one duration class via weighted random."""
        keys = sorted(cls.WEIGHTS.keys())
        weights = [cls.WEIGHTS[k] for k in keys]
        return random.choices(keys, weights=weights, k=1)[0]


# ---------------------------------------------------------------------------
# Configuration and per-call state
# ---------------------------------------------------------------------------

@dataclass(frozen=True)
class PoolConfig:
    """Immutable pool configuration — set once per ``/load/config`` request.

    Validation happens at construction; the config is immutable thereafter
    so asyncio race conditions cannot mutate pool parameters mid-tick.
    """
    target_concurrency: int
    call_rate: float
    enabled_call_types: frozenset[str]

    def __post_init__(self) -> None:
        if not (1 <= self.target_concurrency <= 50):
            raise ValueError(
                f"target_concurrency must be 1..50, got {self.target_concurrency}"
            )
        if not (0.1 <= self.call_rate <= 10.0):
            raise ValueError(f"call_rate must be 0.1..10.0, got {self.call_rate}")
        if not self.enabled_call_types:
            raise ValueError("enabled_call_types must not be empty")
        unknown = self.enabled_call_types - CallModel.ALL_TYPES
        if unknown:
            raise ValueError(f"Unknown call types: {unknown}")


@dataclass
class CallInstance:
    """One call being driven by the generator."""
    call_id: str
    call_type: str
    duration_class: str
    state: str  # "pending" | "invited" | "answered" | "ended"
    far_end_behavior: str  # "answer_and_bye" | "timeout_no_answer"
    started_at: float
    ended_at: float | None = None
```

```python
# tools/call_load_generator.py (append after Task 1 code)

import asyncio
import uuid


class CallPool:
    """Leaky-bucket concurrency pool with refill throttle (ADR-0013).

    Two controls interact via Little's Law (`L = λW`); the binding constraint
    tells the console which control is currently limiting the pool.
    """

    TICK_INTERVAL: Final[float] = 0.5  # seconds between pool checks
    FORCE_TERMINATE_TIMEOUT: Final[float] = 60.0  # seconds before force-cleanup
    RATE_BUDGET_RESET_INTERVAL: Final[float] = 1.0  # seconds

    def __init__(self, config: PoolConfig, mock_uac: Any | None = None):
        self._config = config
        self._mock_uac = mock_uac  # injected for testing; real one in production
        self._lock = asyncio.Lock()
        self.active_calls: int = 0
        self.active_instances: dict[str, CallInstance] = {}
        self._rate_budget: float = config.call_rate  # starts full
        self._last_budget_reset: float = time.monotonic()
        self._running: bool = False
        self._tick_task: asyncio.Task | None = None

    # ------------------------------------------------------------------
    # Lifecycle
    # ------------------------------------------------------------------

    async def start(self) -> None:
        """Start the pool tick loop and fill to target."""
        self._running = True
        self._tick_task = asyncio.create_task(self._tick_loop())
        # First tick fires immediately after TICK_INTERVAL; pre-fill
        await self._tick()

    async def stop(self) -> None:
        """Stop the pool tick loop. Active calls are left to complete."""
        self._running = False
        if self._tick_task is not None:
            self._tick_task.cancel()
            try:
                await self._tick_task
            except asyncio.CancelledError:
                pass
        self._tick_task = None

    async def set_config(self, config: PoolConfig) -> None:
        """Apply new config on the next tick. Already-running calls are
        never force-terminated by a config change.
        """
        async with self._lock:
            self._config = config
            self._rate_budget = config.call_rate
            self._last_budget_reset = time.monotonic()

    # ------------------------------------------------------------------
    # Query
    # ------------------------------------------------------------------

    def active_count(self) -> int:
        return self.active_calls

    def compute_binding_constraint(self) -> str:
        """Return which control is currently binding (ADR-0013)."""
        theoretical = self._config.call_rate * DurationModel.AVG_DURATION_SECONDS
        if theoretical >= self._config.target_concurrency:
            return "concurrency"
        return "rate"

    def snapshot(self) -> dict:
        """Return a JSON-serialisable pool snapshot (for /load/status)."""
        return {
            "active_calls": self.active_calls,
            "target_concurrency": self._config.target_concurrency,
            "call_rate": self._config.call_rate,
            "binding_constraint": self.compute_binding_constraint(),
            "enabled_call_types": sorted(self._config.enabled_call_types),
            "rate_budget_remaining": round(self._rate_budget, 2),
        }

    # ------------------------------------------------------------------
    # Internal — tick loop
    # ------------------------------------------------------------------

    async def _tick_loop(self) -> None:
        while self._running:
            await asyncio.sleep(self.TICK_INTERVAL)
            await self._tick()

    async def _tick(self) -> None:
        # 1. Reset rate budget if a new second has elapsed
        now = time.monotonic()
        elapsed = now - self._last_budget_reset
        if elapsed >= self.RATE_BUDGET_RESET_INTERVAL:
            self._rate_budget = self._config.call_rate
            self._last_budget_reset = now
        else:
            # Proportional budget for partial seconds
            self._rate_budget = min(
                self._rate_budget,
                self._config.call_rate * elapsed + self._rate_budget,
            )
            # Cap at config.max
            self._rate_budget = min(self._rate_budget, self._config.call_rate)

        # 2. Acquire lock — critical section
        async with self._lock:
            pool_deficit = self._config.target_concurrency - self.active_calls
            if pool_deficit <= 0 or self._rate_budget <= 0:
                return

            new_call_count = min(pool_deficit, int(self._rate_budget))
            for _ in range(new_call_count):
                await self._spawn_one_call()
                self._rate_budget -= 1.0

    async def _spawn_one_call(self) -> None:
        call_type = CallModel.pick(self._config.enabled_call_types)
        duration = DurationModel.pick()
        call_id = f"gen-{uuid.uuid4().hex[:12]}"
        behavior = "timeout_no_answer" if duration == "D4" else "answer_and_bye"
        instance = CallInstance(
            call_id=call_id,
            call_type=call_type,
            duration_class=duration,
            state="invited",
            far_end_behavior=behavior,
            started_at=time.monotonic(),
        )

        if self._mock_uac is not None:
            await self._mock_uac.send_invite(
                call_id=call_id,
                call_type=call_type,
                duration_class=duration,
                on_ended=self._on_call_ended,
            )

        self.active_instances[call_id] = instance
        self.active_calls += 1

    # ------------------------------------------------------------------
    # Call completion — called from mock UAC (may be non-asyncio context)
    # ------------------------------------------------------------------

    def _on_call_ended(self, call_id: str, reason: str) -> None:
        """Bridge from sippy thread to asyncio loop."""
        loop = asyncio.get_event_loop()
        loop.create_task(self._async_on_call_ended(call_id, reason))

    async def _async_on_call_ended(self, call_id: str, reason: str) -> None:
        async with self._lock:
            if call_id in self.active_instances:
                del self.active_instances[call_id]
                self.active_calls -= 1
```

```python
class MockSipUac:
    """Sends real SIP INVITEs to an AS and controls far-end behaviour.

    Reuses the :class:`sippy.UA` pattern from ``src/s_sbc_mock/uac.py``
    but runs standalone (not in an AS process). Duration-class-controlled
    far-end behaviour is added here — the s_sbc_mock UAC has no concept
    of "answer then BYE after N seconds" vs "never answer".
    """

    def __init__(self, as_address: str, as_port: int,
                 local_address: str, local_port: int) -> None:
        self.as_address = as_address
        self.as_port = as_port
        self.local_address = local_address
        self.local_port = local_port
        self._loop: asyncio.AbstractEventLoop | None = None
        # Future: start sippy ED2 loop on its own thread and bind a UA

    async def send_invite(self, *, call_id: str, call_type: str,
                          duration_class: str,
                          on_call_ended: Callable[[str, str], None]) -> None:
        """Send one SIP INVITE to the AS.

        Args:
            call_id: Generator-assigned unique ID for this call.
            call_type: Weighted-random type (T1–T6, F1–F4).
            duration_class: Weighted-random duration (D1–D4).
            on_call_ended: Sync callback invoked when the call ends (sippy thread).
        """
        # Determine caller/called numbers from call_type (same as
        # src/s_sbc_mock/main.py scenario selection)
        to, caller = self._numbers_for(call_type)

        if duration_class == "D4":
            # Timeout — never answer 200 OK. AS's 3 s no-answer timer tears down.
            # When AS sends BYE/CANCEL we receive it and call on_call_ended.
            self._send_invite_timeout_case(to, caller, call_id, on_call_ended)
        else:
            # Answer + deferred BYE
            midpoint = DurationModel.MIDPOINTS[duration_class]
            self._send_invite_answer_case(to, caller, call_id, midpoint, on_call_ended)

    # ------------------------------------------------------------------
    # Number selection per call type
    # ------------------------------------------------------------------

    def _numbers_for(self, call_type: str) -> tuple[str, str]:
        """Return (called, caller) for a call type."""
        if call_type == "T1":
            return "+8613800138000", "1001"
        elif call_type == "T2":
            return "02112345678", "1001"
        elif call_type == "T3":
            return "0014155551234", "1001"
        elif call_type == "T4":
            return "1234", "1001"  # short code, no rule match → 404
        elif call_type == "T5":
            return "+8613900139000", "1001"  # reachable next hop
        elif call_type == "T6":
            return "+8613700137000", "1001"  # unreachable next hop
        elif call_type == "F1":
            return "+8613800138000", "1001"  # allow-listed
        elif call_type == "F2":
            return "+8613800138000", "1999"  # block-listed
        elif call_type == "F3":
            return "+8613800138000", "1998"  # high-rate
        elif call_type == "F4":
            return "+8613800138000", "1001"  # missing PAI
        else:
            raise ValueError(f"Unknown call type: {call_type}")

    # ------------------------------------------------------------------
    # Far-end behaviour (to be implemented with real sippy UAC)
    # ------------------------------------------------------------------

    def _send_invite_timeout_case(self, to: str, caller: str, call_id: str,
                                   on_end: Callable) -> None:
        raise NotImplementedError("Requires sippy ED2 loop startup")

    def _send_invite_answer_case(self, to: str, caller: str, call_id: str,
```

```python
# tools/call_load_generator.py (append)

from fastapi import FastAPI, HTTPException, WebSocket, WebSocketDisconnect
from pydantic import BaseModel, Field


class LoadConfigRequest(BaseModel):
    target_concurrency: int = Field(ge=1, le=50)
    call_rate: float = Field(ge=0.1, le=10.0)
    enabled_call_types: list[str]


def build_generator_app(*, pool_state_getter: Callable[[], dict] | None = None,
                          pool_controller: Callable[[str, dict | None], dict] | None = None
                          ) -> FastAPI:
    """Build the generator's FastAPI application.

    Args:
        pool_state_getter: Callable returning the pool's snapshot dict.
            If None, returns a static default (used by standalone tests).
        pool_controller: Callable(action, config_dict_or_None) that dispatches
            start/stop/config actions to the real CallPool.

    Returns:
        A FastAPI app with /load/* routes and /ws/pool WebSocket.
    """
    app = FastAPI(title="Call Load Generator", version="1.0.0")

    @app.get("/load/status")
    async def get_status():
        getter = pool_state_getter or (lambda: {
            "active_calls": 0,
            "target_concurrency": 10,
            "call_rate": 3.0,
            "binding_constraint": "concurrency",
            "enabled_call_types": sorted(CallModel.ALL_TYPES),
            "rate_budget_remaining": 3.0,
        })
        return getter()

    @app.post("/load/start")
    async def start_load():
        if pool_controller:
            result = pool_controller("start", None)
            return {"status": "started", "detail": result}
        return {"status": "started"}

    @app.post("/load/stop")
    async def stop_load():
        if pool_controller:
            result = pool_controller("stop", None)
            return {"status": "stopped", "detail": result}
        return {"status": "stopped"}

    @app.put("/load/config")
    async def set_config(req: LoadConfigRequest):
        try:
            config = PoolConfig(
                target_concurrency=req.target_concurrency,
                call_rate=req.call_rate,
                enabled_call_types=frozenset(req.enabled_call_types),
            )
        except ValueError as exc:
            raise HTTPException(status_code=400, detail=str(exc))
        if pool_controller:
            pool_controller("config", config)
        return {"status": "configured", "config": req.model_dump()}

    @app.websocket("/ws/pool")
    async def pool_feed(ws: WebSocket):
        """Push pool_status_update events to connected clients."""
        await ws.accept()
        try:
            while True:
                snapshot = await get_status()
                await ws.send_json({
                    "timestamp": time.time(),
                    "source": "load_generator",
                    "event": "pool_status_update",
                    "attributes": snapshot,
                })
                await asyncio.sleep(1.0)
        except WebSocketDisconnect:
            pass

    return app
```

```python
def _emit(self, event: str, attributes: dict[str, Any]) -> None:
    """Emit per-call event via internal_api WebSocket broadcast.

    Called from sippy callbacks — may run on sippy's internal thread,
    so we check whether this is the event loop thread and use
    ``run_coroutine_threadsafe`` if needed.
    """
    if self._app is None:
        return
    event_dict = {
        "timestamp": time.time(),
        "source": "as_translation",  # or "as_anti_fraud" in the other controller
        "event": event,
        "call_id": self.call_id,
        "attributes": attributes,
    }
    msg = json.dumps(event_dict, default=str)

    async def _do_broadcast():
        await self._app.state.broadcast(msg)

    try:
        loop = asyncio.get_event_loop()
        # Check if we're on the event loop thread
        if threading.current_thread() is threading.main_thread():
            loop.create_task(_do_broadcast())
        else:
            asyncio.run_coroutine_threadsafe(_do_broadcast(), loop)
    except RuntimeError:
        # No event loop — skip. Happens during unit tests without asyncio.
        pass
```
